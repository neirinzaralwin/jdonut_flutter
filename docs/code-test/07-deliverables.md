# 07 — Deliverables and submission

Reply to the test email with these four items:

1. **Public Git repo** (GitHub/GitLab) with small, readable commits.
2. **Installable builds:** release `.apk` (Android) and zipped `.app` for iOS Simulator (`flutter build ios --simulator`).
3. **Screen recording, 2–4 min:** register, log out, log in, Home, Product detail, Rewards, then the same flow in airplane mode.
4. **README** covering: how to run, Flutter + Dart versions, architecture and folder map, state-management choice, offline strategy, animations built, fake OTP code, known gaps, time spent.

Optional: mock server source + how to run it; CI running analyze and tests.

## Rules
- **Don't commit design screenshots** (client-owned).
- AI tools allowed, but you must be able to explain every line.
- Shortlisted candidates walk through code on a call.

See `../deliverables-checklist.md` for the tick-box version.
